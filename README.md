# EduMatrix - College ERP System

## Overview

EduMatrix is a comprehensive College ERP (Enterprise Resource Planning) System designed to automate and streamline academic and administrative processes within educational institutions.

The system provides a centralized platform for managing students, faculty, attendance, assessments, feedback, academic outcomes, and institutional operations.

## Installation

Clone the repository:

```bash
git clone https://github.com/prathameshmane019/edumatrix.git
```

Install dependencies:

```bash
npm install
```

Create environment variables:

```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

Run the application:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
